Before Page One — Scroll of Spelling

  • Found at the glowing stump-lectern before they step into the book (pressed into the cover, or the Bookworm’s discarded skin of parchment — your call).
  • Each PC may use it once per page/room (rooms 1–5). Does not bank.
  • Effect: change up to 2 letters in one word on a spell or domain card → new effect. You adjudicate generously when it serves a room’s Progress track.
  • Design intent: rooms are built so several different mutations are useful — not one “correct” scroll answer.

Daggerheart countdown reminder

Linked scene: same action roll feeds both tracks.
Progress (good): Fail+Fear 0 · Fail+Hope 0 · Succ+Fear 1 · Succ+Hope 2 · Crit 3
Consequence (bad): Fail+Fear 3 · Fail+Hope 2 · Succ+Fear 1 · Succ+Hope 0 · Crit 0
Start values ~6–8 for a meaty room. Fear spends can poke Consequence extra when telegraphed.

Encounter patterns used (the menu)

1. Linked raceProgress vs Consequence on the same rolls — Hope pulls win, Fear pulls doom.
2. Split laborTwo Progress tracks (or Progress + side objective). Party must fork attention; one scroll can’t solve both.
3. Soft ally / hard threatThing that helps in the nursery myth accelerates Consequence if accepted.
4. Escort accelerantWes’s “hero” choices tick Consequence unless a PC spends a beat stopping him.
5. Bait / forgeWin by creating a substitute the threat prefers — scroll mutates words into bait.
6. Hold the lineProgress = stabilize/slow; Consequence = forced skip. Combat serves the clock, not mop-up.
7. Dual ending tracksTwo Progress clocks (Press vs Talk-out); boss advances Consequence.
8. Multi-site tableExplicit stations (stoke / write / wrestle / ward) so 3–4 PCs have simultaneous jobs.

Five pages

Page 1 · patterns 1, 3, 4, 8
The Warm That Eats Stories
Win: Progress Sate / Bind the Warm hits 0 → it releases the chapter-door.
Lose: Consequence Wes Fed to the Warm hits 0 → big Line hit + door scorched shut (costly reopen) or Warm follows into Page 2.

Progress — Sate / Bind the Warm · start 7

Feed it substitute text · douse/bind its appetite · rewrite its “help” into “stay” · bargain a scrap meal. Stations: Feed · Bind · Seal door hinges.

Consequence — Wes Volunteers · start 7

Advances when rolls go badly and when Wes touches / invites the Warm (escort accelerant). Warm offers help every beat — accepting is free Consequence tick.
  • Clear goals: (A) satisfy Warm without Wes, (B) keep Wes off it, (C) unlock door.
  • Not “carry past”: door won’t open while Warm is hungry. Yeeting Wes through leaves Warm active → Consequence nearly done / follows.
  • Scroll hooks: heat→heal bait, burn→born/bund, flame→frame (cage it), warm→ward, cook→cool, story→store (pantry meal).
Page 2 · patterns 1, 2, 4, 8
The River That Remembers Too Much
Win: BOTH Progress tracks hit 0 (split labor).
Lose: Consequence Ink Tide hits 0 → forced dunks, Line spikes, a verb/name washed into Page 3.

Progress A — Compose the Crossing · start 6

Not “find the ford.” Build a dry path out of remembered sentences: catch floating words, pin them as stepping-stones, mutate spells into bridge/freeze/divert. Needs multiple contributions (several scrolls / several spells).

Progress B — Pin the Remembers-Too-Much · start 6

A predator/current-intellect in the water that dunks Wes and steals verbs. Wrestle, bind, rename, or distract it. Separate station from path-building.

Consequence — Ink Tide · start 8

Linked to action rolls. Fear spends = surge. Wes “swimming the trial” ticks this hard. If A finishes before B, path exists but the thing yanks people off it. If B finishes before A, beast pinned but no path — Tide still rising.
  • Clear goals: (A) compose crossing, (B) pin river-threat, (C) keep Wes dry until both done.
  • Why scrolls matter: one clever freeze helps A; another PC must still mutate something for B (bind/name/lure). Single “I make a bridge” doesn’t clear the room.
  • Scroll hooks: water→wader/wafer path, drown→crown (name the beast), river→rider, sweep→sheep bait, tide→tile (stone path), ink→ink/ank/ilk — you rule.
Page 3 · patterns 1, 5, 4, 8
The Tiny Hungry Choir
Win: Progress Bait & Recover hits 0 (Choir drops the real morsel + you grab it).
Lose: Consequence Nouns Chewed hits 0 → permanent funny blank on Wes (or seed-page ruined) + Line.

Progress — Bait & Recover · start 7

Forge substitute text the Choir prefers → herd them onto it → snatch back Wes’s nouns / seed-page / washed verb from Page 2. Stations: Write bait · Herd · Snatch.

Consequence — Nouns Chewed · start 7

They’re already eating him. Wes reciting = free 2 ticks. Bad rolls chew faster. Recovering mid-chew can restore a noun if Progress wins first.
  • Clear goals: (A) write irresistible bait, (B) move Choir off Wes, (C) recover the morsel.
  • Scroll hooks: mutate card text into bait (“strike”→“sprite”, “brave”→“grave”/“brava”), command→commend, swarm→swarm/swarm→swear (oath-bait), eat→ear (listen instead).
Page 4 · patterns 1, 6, 4
The Wind That Turns Pages Too Fast
Win: Progress Hold the Chapter hits 0 (turners broken or page anchored with Wes still in it).
Lose: Consequence Forced Turn hits 0 → Wes torn alone into Page 5; party arrives late; Bookworm already mid-swallow setup.

Progress — Hold the Chapter · start 7

Kill/drive Page-Turners · silence Wes’s loud heroics · windbreak · weight/anchor the page. Combat serves the clock.

Consequence — Forced Turn · start 7

Gusts + unanswered foes. Wes speeches tick this. Fear = scissors-cavalry surge.
  • Clear goals: (A) reduce turners, (B) keep Wes quiet/anchored, (C) finish Progress before Forced Turn.
  • Scroll hooks: wind→bind/wand, tear→tear/team, haste→haste/hasp (latch), page→cage, next→nest (hold).
Page 5 · patterns 1, 7, 4 · BOSS
The Page With No Words
Win: Either Progress track hits 0 before Consequence / Shatter Line 6.
Boss: Bookworm (purple worm reskin) — burrow, swallow, eat endings. Its attacks and Fear features advance Consequence.

Progress A — Press the Ending · start 6

Gift hero-title → defend Wes while he presses (3 fictional beats mapped to Progress ticks from protect/press assists). Completing = paper-death + Lann gift.

Progress B — Talk Out the Myth · start 8

Harder/longer. Earn that he needn’t die. Advances on sincere social / proof beats. Completing = Lann gift, Wes lives. Wes will not help this track.

Consequence — Bookworm Eats the Ending · start 8

Swallow Wes / chew the blank page / collapse dais. Linked rolls + worm Fear features. At 0: ending destroyed — Lann deleted or worse dump-out. Shatter Line still ticks on paper damage separately.
  • Clear goals: pick Press or Talk-out (can soft-fail one), tank/kill/distract Bookworm, keep Line < 6.
  • Scroll hooks: worm→word/worn, swallow→shallow, burrow→barrow/borrow, blank→bland/brand (title), press→press/prest.
Bookworm: Use purple worm instincts (tunnel, swallow whole, thrash). Fiction: ink-mucus, perforated pages, ozone before it breaches. Killing it is optional if an ending track completes — but a living worm at Consequence 1–2 will try to eat the epilogue on the way out.

Wes · always

  • Introduces as the frail paper-boy / Parchdryad escort — not as Little Spine (that’s the chapbook kid). Begs them into the glowing page as Companions.
  • Reads each page subtitle out loud; picks CYOA skin (A/B/C/D) — costume only.
  • Advances Consequence when he plays the nursery moral (touch Warm, swim trial, recite for Choir, speech in the Wind, insist on Press).
  • Shatter Line 0–6 = paper integrity. Separate from page Consequence clocks (both can doom him).
